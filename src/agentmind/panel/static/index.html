快速引导

1

安装并扫描 Agent

安装 Claude Code、Hermes 等 AI 工具后，打开 AgentMind 总览页点击「扫描新 Agent」自动发现

2

接入飞书

在 AgentMind 配置页填入飞书应用的 App ID 和 Secret，保存并连接即可通过飞书 Bot 发指令

3

多 Agent 讨论

在飞书 Bot 发送 @agent1 @agent2 讨论：话题，多个 Agent 自动轮流发言辩论，发「停」结束并生成总结

4

可视化编排

在 AgentMind 编排页拖拽 Agent 节点构建 DAG 工作流，一键执行多步骤协作任务
